Engineered for Accuracy & Privacy

Every layer is designed to operate autonomously without third-party data tracking or commercial API dependencies.

ANACOM National Plan (PNN)

Full offline resolution for geographic landlines (21 to 296), mobile operators (MEO, Vodafone, NOS, DIGI), and nomadic VoIP prefixes (300-309).

Dynamic Institutional Blocks

70+ dynamic 4 and 5-digit institutional blocks automatically cluster stations and public extensions across 20 districts, eliminating false scam positives.

OSINT Consensus Dorking

Parallel scraping across DuckDuckGo HTML, Brave Search HTML, and Bing. Text regex parser extracts police, hospital, and civic signals even from unofficial websites.

Zero Sensitive Data Leakage

All operations use local databases and open search indices. No user queries, telemetry, or personal lookup history are sent to external analytics.

MBWay & Scam Spike Protection

Detects aggressive telemarketing, silent ping calls, and fraudulent MBWay buyers. Automatically elevates risk to 85-100 CRITICAL on fraud keyword spikes.

105 Automated Tests

Full Pytest automated suite covering phone normalizers, ANACOM ranges, known numbers benchmark (75 entries), and dork signal consensus scoring.

REST API Reference

Available on your local instance at http://127.0.0.1:8000/api/v1

View Swagger / OpenAPI
GET /api/v1/lookup?number={number}&refresh={bool}

Executes the full multi-layer intelligence pipeline against the specified telephone number.

GET /api/v1/admin/directory-stats

Returns statistics on curated vs dynamically scraped police and hospital entries, plus active blocks.

GET /api/v1/admin/coverage-report

Reports district-by-district coverage metrics across all 20 Portuguese administrative regions.

Run Locally in 3 Steps

# 1. Clone the repository

git clone https://github.com/jd164/telefone.git && cd telefone

# 2. Install dependencies

pip install -r requirements.txt

# 3. Start the FastAPI development server

uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
